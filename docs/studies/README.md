# docs/studies

Time-boxed investigations and prototypes — short docs that capture *what we tried, what we learned, what we'd ship if we kept it.*

Different from ADRs: studies are exploratory and may not result in a decision. They're preserved so future work doesn't redo the same prototype.

Suggested format:

```
# <topic>

**Date:** YYYY-MM-DD
**Time-box:** <hours>
**Outcome:** Adopted | Rejected | Inconclusive

## Question
What we were trying to answer.

## What we did
Methodology.

## What we found
Results.

## Recommendation
What we'd do if we picked this up later.
```
